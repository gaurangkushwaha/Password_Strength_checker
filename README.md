Password Strength Checker

A simple Python program that checks whether a password is strong or weak based on common security rules.

Features
Checks minimum password length
Verifies uppercase letters
Verifies lowercase letters
Checks numeric digits
Detects special characters
User-friendly output
Password Rules

A password is considered strong if it contains:

At least 8 characters
One uppercase letter
One lowercase letter
One number
One special character (!@#$%^&*()_+)

Technologies Used
Python 3
